Project — SOC Control Tower

SOC Control Tower

Born from a recurring wall on the floor — the official WMS holds the data, but surfacing anything specific means exporting and pivoting by hand. Built solo end-to-end, from frontend and dashboard logic to authentication infrastructure, using native JavaScript and Firebase — no heavy framework, still real-time and multi-user. Hardened with session-only auth and modular auth guards, and used daily by the Palangka Raya DC operations team.

JavaScript Firebase Auth Realtime Database HTML / CSS Session Auth Guard Audit Trail
The problem

Operational visibility lived in exports, tabs and manual checks.

The WMS contained the data, but specific operational questions still required exporting and pivoting by hand. The system needed one place to surface what mattered during the shift.

The solution

A single control layer for the floor.

A lightweight app-shell brings the operational modules into one interface, keeps Firebase data live, and uses session-based access guards so each user sees only the modules available to them.

My role

End-to-end builder.

Mapped the operational bottleneck, built the frontend and dashboard logic, implemented Firebase authentication and access guards, and carried the system through deployment and daily operational use.

Project — Es Teh Kito

Es Teh Kito — POS Kasir

A point-of-sale system built for a local Es Teh (iced tea) stall, covering the full daily cash flow in one lightweight web app — taking orders, reconciling the cash drawer, keeping transaction history, and generating reports. Built with vanilla JavaScript and Firebase Realtime Database so the counter and the back office stay in sync instantly. Later packaged and sold as a ready-to-use kasir product on FastWork.

JavaScript Firebase Realtime Database POS / Kasir Multi-Device Sync
The problem

A small business needed one simple place for daily transactions.

Ordering, cash tracking, transaction history and reporting are easy to scatter across notebooks or separate tools. The goal was a focused POS that needs no installation.

The solution

A lightweight realtime POS.

The cashier and owner can work from different devices while Firebase keeps both views synchronized, with optional authentication for controlled access.

My role

Web app builder & product delivery.

Built the browser-based POS around the business cash-flow workflow, implemented realtime Firebase synchronization and optional authentication, and delivered it as a ready-to-use freelance product.
